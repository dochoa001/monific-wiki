(dims used: 1000 rows x 1 cols; showing 400 x 1)
MONIFIC · Plantillas de WhatsApp para Meta Business
Insumo para carga en WhatsApp Manager (Meta)
Propósito
Contiene las 11 comunicaciones por WhatsApp definidas en la Matriz completa de comunicación (10 exclusivas de WhatsApp + COB-020, que combina Email + WhatsApp). Fuente: '03. Matriz completa de comunicación.docx' y '04. Tracker Matriz Comunicaciones.xlsx'.
Cómo se usa
Cada fila de la pestaña «Plantillas WhatsApp» corresponde a una plantilla a crear en Meta. Los textos usan variables numeradas {{1}}, {{2}}, {{3}}... como las pide Meta; revisa la pestaña «Variables y ejemplos» para saber a qué campo de HubSpot corresponde cada una y qué valor de ejemplo usar al darla de alta.
Categoría (Marketing / Utilidad / Autenticación)
Es una propuesta de Monific con base en el contenido de cada mensaje; revísala antes de enviar a revisión de Meta, ya que una categoría incorrecta puede causar rechazo del template.
Botón / Link CTA
Cuando el botón es de respuesta rápida (quick reply) el link queda vacío. Cuando el botón abre una URL dinámica, el link muestra la variable ({{1}}, {{2}}...) y, entre paréntesis, el campo de HubSpot que la alimenta. Las URLs fijas (ej. app.monific.com) se muestran completas.
Fecha de creación
